۱دریافت کلید از پلتفرم Z.AI

رسا برای فکرکردن و پاسخ‌دادن به یک مدل زبانی نیاز دارد. این پروژه به‌صورت پیش‌فرض روی مدل GLM شرکت Z.AI تنظیم شده و ارائه‌دهندهٔ zai به‌صورت توکار پشتیبانی می‌شود؛ فقط کافی است یک کلید API بگیرید.

۱ثبت‌نام یا ورود به پلتفرم

به پلتفرم متن‌باز Z.AI (Open Platform) بروید و با ایمیل خود حساب بسازید یا وارد شوید. ثبت‌نام با گوگل هم امکان‌پذیر است. اگر قبلاً در Z.AI یا Zhipu حساب دارید، با همان حساب وارد شوید.

۲شارژ حساب (در صورت نیاز)

به صفحهٔ صورت‌حساب و پرداخت (Billing) بروید. برخی حساب‌های جدید اعتبار آزمایشی رایگان دریافت می‌کنند؛ اگر ندارید، مبلغ کمی (مثلاً ۵ دلار) شارژ کنید. برای کار روزانه، کارت بانکی بین‌المللی لازم است.

💡

کدنویس حرفه‌ای هستید؟ طرح GLM Coding Plan از حدود ۱۸ دلار در ماه، دسترسی ماهانه به مدل‌های قدرتمند را ارزان‌تر از پرداختِ به‌ازای هر توکن می‌کند.

۳ساخت کلید API

به صفحهٔ مدیریت کلیدها (API Keys) بروید و دکمهٔ ساخت کلید جدید را بزنید. نوع Standard API Key را انتخاب کنید — همین نوع برای رسا مناسب است. یک نام دلخواه (مثلاً rasa) بگذارید و تأیید کنید.

۴کپی و نگهداری امن کلید

کلید ساخته‌شده را بلافاصله کپی کنید — برخی پلتفرم‌ها بعد از بستن پنجره دیگر کل کلید را نشان نمی‌دهند. کلید چیزی شبیه xz_•••••••••••••••••••• است. آن را فقط در فایل .env محلی نگه دارید؛ هرگز در گروه، اسکرین‌شات یا گیت کامیت نکنید.

۲جای‌گذاری کلید در رسا

بعد از اینکه کلید را گرفتید، طبق سیستم‌عامل خود یکی از سه روش زیر را انتخاب کنید. هر سه روش کارِ یکسانی می‌کنند: کلید را در ~/.hermes/.env می‌گذارند و پیکربندی مدل را روی zai تنظیم می‌کنند.

🌙 پیشنهادی برای ویندوز — اسکریپت PowerShell

در پوشهٔ پروژه (D:\Projects\hermes-agent-fa)، کلید را مستقیم به اسکریپت بدهید تا دیگر سوالی پرسیده نشود:

# در PowerShell، از ریشهٔ پروژه:
.\scripts\rasa_glm_setup.ps1 -ApiKey "کلید-شما"

یا حالت تعاملی (کلید را می‌پرسد):

.\scripts\rasa_glm_setup.ps1

اگر پیام خطای سیاست اجرا (Execution Policy) دیدید:

powershell -ExecutionPolicy Bypass -File .\scripts\rasa_glm_setup.ps1

اسکریپت Bash (Git Bash / لینوکس / مک)

کلید را به‌صورت آرگومان بدهید — این همان روشی است که مشکل «✗ کلید خالی است» را کاملاً حل می‌کند:

# ویندوز (Git Bash) — پوشهٔ پروژه:
cd /d/Projects/hermes-agent-fa
bash scripts/rasa_glm_setup.sh "کلید-شما"

# لینوکس / مک:
bash scripts/rasa_glm_setup.sh "کلید-شما"

یا با متغیر محیطی:

GLM_API_KEY="کلید-شما" bash scripts/rasa_glm_setup.sh

روش دستی — بدون هیچ اسکریپتی

در PowerShell (ویندوز):

New-Item -ItemType Directory -Force -Path "$env:USERPROFILE\.hermes" | Out-Null
Add-Content -Path "$env:USERPROFILE\.hermes\.env" -Value 'GLM_API_KEY=کلید-شما'
Copy-Item config.rasa.example.yaml "$env:USERPROFILE\.hermes\config.yaml"

در Bash (لینوکس / مک / Git Bash):

mkdir -p ~/.hermes
echo 'GLM_API_KEY=کلید-شما' >> ~/.hermes/.env
cp config.rasa.example.yaml ~/.hermes/config.yaml

اگر فایل config.yaml از قبل تنظیمات دیگری دارد، فقط بخش model: را مطابق config.rasa.example.yaml ویرایش کنید تا بقیهٔ تنظیمات حفظ شود.

⚠️

جای «کلید-شما» کلید واقعی خودتان را بگذارید (همراه با گیومه). مثال: -ApiKey "xz_1234abcd…"

۳اجرای رسا و رفع خطای «rasa is not recognized»

دستور rasa بعد از نصب پکیج پایتون پروژه در دسترس قرار می‌گیرد. اگر پیام «rasa is not recognized» گرفتید، یعنی هنوز نصب نشده — فقط یک‌بار این مراحل را انجام دهید:

۱راه رسمی پروژه (پیشنهادی)

# در PowerShell، از ریشهٔ پروژه:
cd D:\Projects\hermes-agent-fa
.\activate.ps1      # محیط را می‌سازد و فعال می‌کند (بار اول چند دقیقه طول می‌کشد)
rasa                # 🌙 اجرای ماه‌افزار هوشمند رسا

۲راه جایگزین (نصب دستی)

cd D:\Projects\hermes-agent-fa
pip install -e .    # نصب پروژه به‌صورت قابل‌ویرایش + ثبت دستور rasa
rasa

اگر pip در دسترس نبود، از python -m pip install -e . استفاده کنید. بعد از نصب، اگر ترمینال را بستید و دوباره باز کردید لازم نیست دوباره نصب کنید — فقط activate.ps1 یا محیط مجازی را فعال نگه دارید.

✓

بعد از اجرا: با دستور /model می‌توانید مدل را عوض کنید و با hermes doctor سلامت پیکربندی را ببینید. رابط کاربری به‌صورت خودکار فارسی است.

۴تست صحت کلید (اختیاری)

قبل از اجرای رسا می‌توانید با یک درخواست ساده مطمئن شوید کلید کار می‌کند:

با curl

curl -X POST "https://api.z.ai/api/paas/v4/chat/completions" \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer کلید-شما" \
  -d '{"model": "glm-5.3", "messages": [{"role": "user", "content": "سلام"}]}'

با پایتون (SDK رسمی)

# نصب:  pip install zai-sdk
from zai import ZaiClient

client = ZaiClient(api_key="کلید-شما")
r = client.chat.completions.create(
    model="glm-5.3",
    messages=[{"role": "user", "content": "سلام! خودت را معرفی کن"}],
)
print(r.choices[0].message.content)

اگر پاسخ مدل را دیدید، همه‌چیز آماده است. فهرست کامل مدل‌ها در مستندات رسمی Z.AI موجود است.

۵عیب‌یابی مشکلات رایج

مشکلراه‌حل
✗ کلید خالی است
(موقع اجرای اسکریپت Bash)		کلید را به‌صورت آرگومان بدهید: bash scripts/rasa_glm_setup.sh "کلید" — یا در ویندوز از اسکریپت PowerShell با -ApiKey استفاده کنید.
خطای 401 / Invalid API keyکلید ناقص کپی شده یا اشتباه است. در صفحهٔ API Keys یک کلید جدید بسازید و دوباره تنظیم کنید. مطمئن شوید گیومه‌های ابتدا و انتها وارد فایل نشده‌اند.
Insufficient balanceاعتبار حساب تمام شده. از صفحهٔ Billing شارژ کنید؛ یا اگر با مدل‌های گران آزمایش می‌کنید، موقتاً از glm-5.2 یا glm-4.5-flash استفاده کنید.
Model not foundنام مدل را بررسی کنید — پیش‌فرض رسا glm-5.3 است. با دستور hermes model مدل را عوض کنید.
rasa شناخته نشدپکیج نصب نیست → بخش ۳ همین راهنما: .\activate.ps1 یا pip install -e .
تایم‌اوت یا قطعی شبکهاگر از پروکسی استفاده می‌کنید، در ~/.hermes/.env مقدار GATEWAY_PROXY_URL را تنظیم کنید.
حروف فارسی به‌هم‌ریخته در ترمینالاز Windows Terminal استفاده کنید و یک‌بار chcp 65001 را اجرا کنید تا کدپیج UTF-8 شود.

۶نکات امنیتی مهم

🔐

کلید API محرمانه است: هر کسی که کلید را داشته باشد با حساب شما صحبت می‌کند و هزینه‌اش را شما می‌پردازید. کلید فقط در ~/.hermes/.env بماند (این فایل به‌صورت پیش‌فرض خارج از گیت است).

🔐

توکن GitHub که در گفتگو فرستادید: چون در متن چت به‌صورت خام آمده، بعد از پایان کار حتماً آن را باطل (Revoke) کنید: GitHub → Settings → Developer settings → Personal access tokens → Delete. کلید API را هم اگر جایی به اشتراک گذاشتید، از همان صفحهٔ API Keys با دکمهٔ Regenerate بازسازی کنید.
